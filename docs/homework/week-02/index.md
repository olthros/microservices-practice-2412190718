# 作业 02：项目选题与功能规划

## 项目选题
- **项目名称**：健身房会员管理系统
- **选题过程说明**：
  在课程提供的多个选题方向中，我最终选择健身房系统，原因如下：
  1. **业务链条完整**：涵盖了卡务、排课、预约、签到、支付等清晰的业务节点，便于后续逐步实践微服务拆分。
  2. **角色边界清晰**：管理员、教练、会员三种角色之间的交互逻辑非常明确，方便微服务鉴权与划分。
  3. **贴近现实**：自身有健身房会员经理，能更好的分析用户需求

## 功能规划
- **本周完成内容**：
  1. 完成并更新了根目录的 `README.md`，明确了项目背景、目标用户、核心功能模块。
  2. 使用 Markdown 表格呈现了角色需求和功能划分。
  3. 使用 Mermaid 绘制了会员预约和签到扣课的核心业务流程图。
  4. 明确了当前范围以及后续的技术演进方向（认证、服务拆分、消息、监控、部署）。
- **后续计划**：
