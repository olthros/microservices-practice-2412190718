# 项目提案 (Project Proposal)

## 项目名称
健身房会员管理系统

## 目标用户
- **管理员**：负责会员卡种管理、教练排班和系统设置。
- **教练**：查看排课、确认学员签到。
- **会员**：购买会员卡/课包、在线预约课程、到店签到。

## 优先实现业务场景
**会员课程预约与签到**：会员登录后，查看可预约课程并完成预约。到店后通过系统签到，系统自动扣减课时，教练确认核销。这是健身房最核心、最高频的业务环节。

## 核心模型 (Domain Models)
1. **会员 (Member)**：存储会员基本信息、会员卡状态、剩余课时等。
2. **课程 (Course)**：存储课程名称、教练、上课时间、容量限制等。
